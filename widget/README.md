# Home-page widget

Small stats widget embedded on the Changing Transport home page
(changing-transport.org) as an `<iframe>`. Shows three headline numbers
about NDC 3.0 transport content plus two navigation tiles into the Tracker.

## Files in this folder

| File | Purpose |
|---|---|
| `index.html` | The widget itself. Self-contained HTML/CSS/JS, no build step. |
| `widget-summary.json` | The three stat numbers, regenerated by the pipeline on every run. |
| `tracker.jpg` | Circular logo shown in the widget header — the Tracker's own visual identity, separate from the Changing Transport site logo above it, so visitors recognise they're entering a distinct product. |
| `widget_old.html` | Previous version, kept for reference. Not linked from anywhere live. |

## Where the numbers come from

`widget-summary.json` is generated at the end of `pipeline/update_data.py`
(the same block is kept as a standalone reference copy in
`pipeline/widget_snippet.py`). It runs after the main dashboard data is
built, reusing numbers already computed for the gen3 (NDC 3.0) tab rather
than re-parsing the Excel file.

**NDCs 3.0 submitted** — count of countries whose most recent NDC is a
third-generation submission (`tab1.generations.gen3.total_submitted`).
Denominator is `169`, the total number of Parties expected to submit.

**With transport targets** — of those, how many have at least one
transport-relevant target in that NDC (`tab1.generations.gen3.with_transport`).

**With transport measures** — of those, how many have at least one
transport mitigation measure in their latest active document. This one
needs a bit of care (see below).

### The EU bloc

The EU submits one collective NDC on behalf of its 27 member states. The
pipeline copies that collective NDC's data onto each of the 27 member
country records, so every EU country's profile page shows the right
information. That's correct everywhere **except** here: if the widget
counted "with transport measures" by scanning per-country records, it
would count the EU 27 times, while the denominator (`total_submitted`)
counts the EU once as a single bloc (code `EEU`). That mismatch is what
produced an impossible 110%+ figure before this was fixed.

### Regenerating

Numbers update automatically every time the pipeline runs — no manual
step needed:

```
python pipeline/update_data.py
```

This overwrites `widget-summary.json` with fresh numbers and today's date.
Nothing else in this folder needs to change for a routine data refresh.

## How the iframe embed works

`index.html` is self-updating: on load it fetches `widget-summary.json`
from the same folder and renders the three stat cards from it. If the
fetch fails (e.g. the file briefly unavailable during a deploy), it falls
back to a small hardcoded dataset in the `<script>` block so the widget
never shows a broken state.

Because GitHub Pages serves this folder as-is, embedding it is a plain
iframe pointing at the published `index.html` — no server-side rendering
or manual sync required on the Changing Transport side. Every time
`pipeline/update_data.py` runs and the change is pushed, the next person
who loads the home page sees the new numbers automatically.

### Auto-height

The widget doesn't know how tall it will render (font loading, content
changes), so it posts its own height to the parent window after the
stat-card bars finish animating:

```js
window.parent.postMessage({ iframeHeight: h }, '*');
```

The parent page needs a small listener to resize the iframe on
`message` events with an `iframeHeight` payload. This already exists
in principle for other Tracker iframes on the site; if the widget iframe
doesn't resize correctly, check that this listener is wired up for its
specific iframe id — this is coordination needed with Akrem on the
WordPress side.

### Suggested embed snippet

```html
<iframe
  src="https://<github-pages-domain>/widget/index.html"
  style="width:100%; border:0;"
  loading="lazy"
  title="NDC Transport Tracker — headline stats">
</iframe>
```

Replace the `src` with the actual published GitHub Pages URL for this
repo. The iframe's domain needs to be whitelisted in the Borlabs Cookie
plugin on changing-transport.org for the embed to render (same
requirement as the other Tracker iframes already on the site).

## Where it links

| Element | Links to |
|---|---|
| Widget header / logo | Not a link — visual identity only. |
| "Country explorer" tile | `https://changing-transport.org/tracker/` |
| "Compare NDCs" tile | `https://changing-transport.org/tracker/compare-ndc` |
| "Explore the Tracker" button | `https://changing-transport.org/tracker/` |

All three open in a new tab (`target="_blank"`), since the widget itself
lives inside an iframe on the Changing Transport home page — navigating
the iframe in place would trap the visitor inside the widget's own frame.
